# XEØRUM Web

## Deployment
- Frontend target: Netlify.
- Backend public API: `https://xeorum-backend-production.up.railway.app`.
- Required env for Netlify: `NEXT_PUBLIC_API_BASE_URL=https://xeorum-backend-production.up.railway.app/api/v1`.

## Local development
- Local fallback API: `http://localhost:3001/api/v1`.
